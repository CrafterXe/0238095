# #0238095 · 本地 AI 陪伴

一个**完全本地运行**的 AI 对话陪伴应用：真实的角色对话（本地大模型）+ 本地语音合成（GPT-SoVITS）+ 网页面板。所有数据存在你自己的电脑上，离线可用，可自由备份、移植。

> 切换人物项目即切换性格、记忆、对话历史。每个人物都是独立的存在。

## 特性

- **多人物系统** —— 每个角色独立的人设、记忆、对话历史、语音存档，下拉即切换
- **活人感对话** —— 情绪反应、状态惯性、主动搭话，拒绝模板化回复
- **本地语音** —— GPT-SoVITS 合成，回复自动朗读，音色可自定义训练
- **长期记忆** —— 自动记住你说过的重要的事，越聊越懂你
- **完全离线** —— 大模型、语音合成全在本地，不经过任何云端
- **可移植** —— 整个文件夹拷走即用，数据全在目录内

## 工作原理

```
你 ──> 网页面板 (Gradio, :14001)
         ├─> 本地大模型 (Ollama, :11434)   ← 负责"想"：生成回复文字
         └─> 语音合成 (GPT-SoVITS, :9880)  ← 负责"说"：文字转语音
```

三个本地服务通过 localhost 通信，面板是唯一入口。

## 系统要求

| 项目  | 要求                                                |
| --- | ------------------------------------------------- |
| 系统  | Windows 10 / 11（64 位）                             |
| 显卡  | NVIDIA，**显存 ≥ 8GB**（对话模型 + 语音模型同时驻留约需 7.7GB）      |
| 硬盘  | 约 25 GB 可用空间（引擎 8GB + 对话模型 5GB + 语音模型 0.3GB + 缓存） |
| 网络 | **首次安装需联网**，且需能访问 GitHub（语音模型）和 HuggingFace（语音引擎），建议开启 VPN |

> 没有 NVIDIA 显卡也能跑，但语音合成和对话会慢很多，不推荐。

## 安装（首次，约需下载 13GB）

1. **下载本仓库**（Code → Download ZIP，或 `git clone`），解压到任意位置。
2. **双击 `install.bat`**，耐心等待。它会自动完成：
   - 下载并解压 GPT-SoVITS 语音引擎（约 8 GB）
   - 下载语音模型（默认音色；只需下载约 129 MB 的 `sf_e8_s144.pth`，GPT 底模 `s1v3.ckpt` 用引擎自带的）
   - 安装 Ollama（本地大模型服务）
   - 下载对话模型 `qwen3-8b`（约 5 GB）
3. 中途若提示安装 Ollama，按提示操作后**重新双击 `install.bat`** 继续。

> 全部支持断点续传，中断了重跑 `install.bat` 即可，会自动跳过已完成部分。

## 启动（每次使用）

**双击 `start.bat`**，然后用浏览器打开：

```
http://127.0.0.1:14001/
```

首次启动语音服务需约 1 分钟加载模型，请耐心等待面板就绪。

## 使用流程

1. **新建人物**：顶部输入名字 → 点"新建项目"
2. **写人设**：把角色的设定/小说片段放进 `projects/<名字>/initial files/`，点"提取人物特征"生成人设模板，再手动补全
3. **开始聊天**：输入消息，她会以人设回复并自动朗读
4. **教她记你**：聊得越多她记得越多；也可以发"记住……"让她立刻记住

详细说明见面板内提示。

## 目录结构

```
J1/
├─ install.bat / install.py   ← 一键安装（下载引擎与模型）
├─ start.bat                  ← 一键启动
├─ app.py                     ← 网页面板主程序
├─ config.py                  ← 配置（端口、路径、生成参数）
├─ core/                      ← 对话、记忆、人物、语音等核心逻辑
├─ tools/                     ← TTS 启动脚本、7zr 解压器
├─ assets/                    ← 默认音色参考音频
├─ engine/                    ← [安装后生成] GPT-SoVITS 语音引擎
├─ voice_model/               ← [安装后生成] 语音模型权重
└─ projects/                  ← [运行后生成] 各人物的对话与记忆
```

## 自定义音色

默认附 sweetiefox 英文音色。想换成自己的声音：

- 音色模型可从社区下载，或用 GPT-SoVITS 自行训练（训练音频放入项目即可，详见 [model-files](https://github.com/CrafterXe/model-files) 说明）
- 训练对显存要求较高（建议 12GB+）

## 常见问题

**Q：启动后语音没声音 / 报错？**
A：首次启动语音服务需约 1 分钟。若持续报错，检查显存是否足够（关掉其他占显存的程序）。

**Q：下载引擎/模型卡住或中断？**
A：语音模型从 GitHub 下载，引擎从 HuggingFace 下载，请确保能访问这两个站点（建议开 VPN）。下载支持断点续传，中断后重新双击 `install.bat` 会从断点继续。

**Q：可以不联网用吗？**
A：首次安装必须联网下载引擎和模型。安装完成后**完全离线可用**。

**Q：数据存在哪？安全吗？**
A：全部存在 `projects/` 目录，纯本地文件，不上传任何云端。备份整个文件夹即可。
