# #0238095 · 本地 AI 陪伴

一个**完全本地运行**的 AI 对话陪伴应用：真实的角色对话（本地大模型）+ 本地语音合成（GPT-SoVITS）+ 网页面板。所有数据存在你自己的电脑上，离线可用，可自由备份、移植。

> 切换人物项目即切换性格、记忆、对话历史。每个人物都是独立的存在。

## 特性

- **多人物系统** —— 每个角色独立的人设、记忆、对话历史、语音存档，下拉即切换
- **活人感对话** —— 情绪反应、状态惯性、主动搭话，拒绝模板化回复
- **本地语音** —— GPT-SoVITS 合成，回复自动朗读，音色可自定义训练
- **长期记忆** —— 自动记住你说过的重要的事，越聊越懂你
- **完全离线** —— 大模型、语音合成全在本地，不经过任何云端
- **可移植** —— 整个文件夹拷走即用，数据全在目录内

## 工作原理

```
你 ──> 网页面板 (Gradio, :14001)
         ├─> 本地大模型 (Ollama, :11434)   ← 负责"想"：生成回复文字
         └─> 语音合成 (GPT-SoVITS, :9880)  ← 负责"说"：文字转语音
```

三个本地服务通过 localhost 通信，面板是唯一入口。

## 系统要求

| 项目  | 要求                                                |
| --- | ------------------------------------------------- |
| 系统  | Windows 10 / 11（64 位）                             |
| 显卡  | NVIDIA，**显存 ≥ 8GB**（对话模型 + 语音模型同时驻留约需 7.7GB）      |
| 硬盘  | 约 25 GB 可用空间（引擎 8GB + 对话模型 5GB + 语音模型 0.3GB + 缓存） |
| 网络 | **首次安装需联网**，且需能访问 GitHub（语音模型）和 HuggingFace（语音引擎），建议开启 VPN |

> 没有 NVIDIA 显卡也能跑，但语音合成和对话会慢很多，不推荐。

## 安装（首次，约需下载 13GB）

1. **下载本仓库**（Code → Download ZIP，或 `git clone`），解压到任意位置（建议路径不含中文和空格）。
2. **双击 `install.bat`**，耐心等待。它分两个阶段自动完成：
   - **阶段 A（纯批处理，无需 Python）**：下载并解压 GPT-SoVITS 语音引擎（约 8.2GB，HuggingFace 官方源，断点续传 + 最多 3 轮重试 + 体积校验）
   - **阶段 B（自动调用 install.py）**：下载语音模型（`sf_e8_s144.pth`，按 134946355 字节精确校验；GPT 底模 `s1v3.ckpt` 引擎自带，无需下载）→ 通过 winget 安装 Ollama → 下载对话模型 `qwen3-8b`（约 5GB）
3. 中途若提示安装 Ollama，按提示操作后**重新双击 `install.bat`** 继续。

> 全部下载支持断点续传与多轮重试（每源最多 5 轮、退避 5/10/20/30 秒、连接超时 8 秒）；中断后重跑 `install.bat` 会自动跳过已完成部分。最终失败时会打印手动下载地址与应保存路径，照做即可（详见 [发布说明.md](发布说明.md) 的「安装失败自救」对照表）。

## 启动（每次使用）

**双击 `start.bat`**，它会依次完成四步，窗口里有进度提示：

1. 定位引擎自带的嵌入式 Python（找不到会提示先运行 install.bat）
2. 检查 Ollama，没运行则自动后台拉起
3. 校验语音权重并启动语音服务（详见下方说明）
4. 启动网页面板

然后用浏览器打开：

```
http://127.0.0.1:14001/
```

- 首次启动语音服务需约 1 分钟加载模型，窗口每 3 秒打一个点，最长等待 3 分钟；超时也会照常开面板，文字聊天不受影响
- 若 `voice_model\sf_e8_s144.pth` 缺失或大小不对（应恰好 134946355 字节），会打印 [WARN] 与手动下载指引，并以 `(voice disabled)` 模式启动面板；补齐文件后重跑 start.bat 即可恢复语音

## 使用流程

1. **新建人物**：顶部「新建项目名」输入名字 → 点「新建项目」（自动追加日期后缀）
2. **写人设**：把角色的设定/小说片段放进 `projects/<名字_日期>/initial files/`（示例对话、正反例可写入同目录的 `用户补充.md`），点「提取人物特征」生成 `人物设定.md`，再手动补全
3. **开始聊天**：输入消息回车，她会以人设回复并自动朗读；每聊满 5 轮自动提取记忆，发「记住……」可让她立刻记住
4. **她会主动找你**：沉默约 10 分钟，她会以人设主动搭话（间隔与触发时间可在 `config.py` 调整）

详细步骤见 [发布说明.md](发布说明.md) 与面板内提示。

## 目录结构

```
J1/
├─ install.bat / install.py   ← 一键安装（下载引擎与模型）
├─ start.bat                  ← 一键启动
├─ app.py                     ← 网页面板主程序
├─ config.py                  ← 配置（端口、路径、生成参数）
├─ core/                      ← 对话、记忆、人物、语音等核心逻辑
├─ tools/                     ← TTS 启动脚本、7zr 解压器
├─ assets/                    ← 默认音色参考音频
├─ engine/                    ← [安装后生成] GPT-SoVITS 语音引擎
├─ voice_model/               ← [安装后生成] 语音模型权重
└─ projects/                  ← [运行后生成] 各人物的对话与记忆
   └─ <名字_日期>/
      ├─ memory settings/     ← 人设 + 动态记忆
      ├─ chats/               ← 对话记录
      ├─ audios of the conversation/  ← 语音存档
      └─ initial files/       ← 设定源文件（仅新建时提取一次）
```

## 自定义音色

默认附 sweetiefox 英文音色。想换成自己的声音：

- 音色模型可从社区下载，或用 GPT-SoVITS 自行训练（训练音频放入项目即可，详见 [model-files](https://github.com/CrafterXe/model-files) 说明）
- 把新的 SoVITS 音色模型放进 `voice_model\` 并修改 `config.py` 里的 `SOVITS_WEIGHTS` 文件名
- 训练对显存要求较高（建议 12GB+）

## 常见问题

**Q：启动后语音没声音 / 报错？**
A：首次启动语音服务需约 1 分钟。若面板标题带 `(voice disabled)` 或启动窗口有 [WARN]，说明 `voice_model\sf_e8_s144.pth` 缺失或大小不对（应恰好 134946355 字节），按窗口里的指引补齐后重跑 start.bat。持续报错请检查显存并查看 `logs\tts_api.log`。

**Q：下载引擎/模型卡住或中断？**
A：语音模型从 GitHub 下载，引擎从 HuggingFace 下载，请确保能访问这两个站点（建议开 VPN）。全部下载支持断点续传与多轮重试，中断后重新双击 `install.bat` 会从断点继续；最终失败时会打印手动下载地址与保存路径（另见 [发布说明.md](发布说明.md) 的对照表）。

**Q：voice_model 里为什么只有 sf_e8_s144.pth 一个文件？**
A：GPT 底模 `s1v3.ckpt` 在引擎集成包内自带，`config.py` 直接指向引擎内文件，不需要重复下载。

**Q：可以不联网用吗？**
A：首次安装必须联网下载引擎和模型。安装完成后**完全离线可用**。

**Q：数据存在哪？安全吗？**
A：全部存在 `projects/` 目录，纯本地文件，不上传任何云端。备份整个文件夹即可。
